PhD Research Objectives & Implementation Mapping

Objective 1

ANN-Based Adaptive Security Framework

"To provide an ANN based security framework that is adaptive, self-learning, and capable of autonomous response, threat prediction, and real-time anomaly detection in heterogeneous cloud computing environments."

How We Implemented It:
  • CICIDS2018 Features: 80-dimensional flow extraction (flow duration, inter-arrival times, TCP flags).
  • Deep Autoencoder & LSTM: Unsupervised manifold learning with calibrated reconstruction error threshold (τ = 0.000784).
  • Adaptive Retraining: Sliding-window FIFO buffer fine-tunes model on verified benign batches to defeat concept drift.
  • Autonomous Response: Sub-second automated quarantine and traffic throttling policy engine.
Objective 2

Hybrid Decentralized Security Architecture (PQC + Blockchain)

"To create and implement a hybrid decentralized security architecture that combines quantum-resistant cryptographic techniques with blockchain-enabled trust management to guarantee improved data integrity, confidentiality, tamper-proof auditing, and secure communication."

How We Implemented It:
  • CRYSTALS-Kyber768: NIST Round-3 Key Encapsulation derives 256-bit symmetric keys for quantum-safe container channels.
  • CRYSTALS-Dilithium3: Lattice-based digital signatures sign every inter-node transaction and threat alert.
  • Permissioned Blockchain: SHA-256 Merkle hash chain records all detection events and dynamic node trust scores (T ∈ [0.0, 1.0]).
  • Tamper Proofing: Any manual byte modification invalidates the cryptographic hash chain instantly.
Objective 3

Verification — Robustness, Scalability, Dependability, Efficiency

"To verify the robustness and practical application of the hybrid decentralized security framework by thoroughly assessing its efficacy, scalability, dependability, and computing efficiency using benchmark datasets, actual cloud workloads, and simulated attack scenarios."

How We Implemented It:
  • Efficacy: Autoencoder achieves 90.68% accuracy and 0.7147 F1, significantly outperforming Isolation Forest (0.6313) and One-Class SVM (0.6319) (p < 0.001).
  • Scalability: Benchmarked smoothly from 5 up to 50 nodes with sub-linear latency growth.
  • Dependability: Automated node crash/revival test verifies consensus survival and ledger synchronization.
  • Computing Efficiency: Ultra-fast 5.99 ms inference latency enables inline real-time cloud traffic inspection.
